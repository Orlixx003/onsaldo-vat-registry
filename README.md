# Rejestry i VAT — редизайн экрана (тестовое задание)

Рабочий прототип экрана «Rejestry i VAT»: React + TypeScript + Vite, без UI-библиотек (только `lucide-react` для иконок).
Цвета и общий визуальный стиль сохранены, структура экрана переосмыслена.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

Деплой на Vercel: импортировать репозиторий — Vercel сам определит Vite (Build: `npm run build`, Output: `dist`).

## Что изменено и почему

| Было | Стало |
|---|---|
| Две вкладки + отдельная панель из 4 селектов (Rok, Miesiąc, Rodzaj operacji, Kod JPK V7) | Главное на виду: переключатель **Sprzedaż / Zakupy** (со счётчиком документов) и **один выбор периода** «‹ Październik 2026 ›». Rodzaj operacji, Kod JPK V7 и Serie dokumentów — в панели **Filtry** (со счётчиком активных фильтров и чипами, которые снимаются в один клик) |
| 4 иконки без подписей (тег, печать, загрузка, настройки) | Меню **⋯**: Eksportuj CSV (работает), Drukuj (print-стили), Etykiety, Ustawienia kolumn |
| Перетаскивание колонок за «ручки» | Ustawienia kolumn: показать/скрыть и порядок колонок |
| Жёлтый баннер на всю ширину | Компактный статус «Wymaga potwierdzenia» + «DEMO»; полный текст — по клику |
| Netto / VAT / Brutto одинакового веса + всегда открытые полосы ставок | Акцент на **Brutto**; разбивка по ставкам VAT раскрывается по запросу и показывает и netto, и VAT |
| Строка без сумм, детали скрыты за кнопкой | Добавлена колонка Brutto, сортировка по клику на заголовок, клик по строке раскрывает все поля документа (NIP, даты, серия, операция, JPK, ставка, netto/VAT/brutto, KSeF, идентификатор) |

Ни одно поле и действие не удалено — всё дополнительное убрано в меню/панели.

## Состояния

Переключатель **Stan** внизу экрана (или параметр URL):

- `/` — данные (заполненный);
- `/?state=empty` — пустой (нет документов за период);
- `/?state=error` — ошибка загрузки с кнопкой «Spróbuj ponownie»;

плюс естественные состояния: загрузка (skeleton), «Nic nie znaleziono» при поиске/фильтрах без результатов, пустой месяц (например, листопад 2026).

## Адаптивность

- Desktop — таблица; ≤ 760 px — карточки документов, фильтры и меню открываются как bottom sheet;
- проверено на 1440, 900, 375 (iPhone SE) и 320 px — без горизонтального скролла страницы.

Дополнительно: тёмная тема, доступность с клавиатуры (Esc закрывает поповеры, aria-атрибуты), `prefers-reduced-motion`.

## Структура

```
src/
  data/demo.ts            демо-данные + имитация запроса
  lib/                    форматирование (pl-PL), хуки
  components/
    AppHeader.tsx         шапка приложения, уведомления, профиль, разделы
    RegistryPage.tsx      экран: состояние, фильтрация, сортировка, пагинация
    Toolbar.tsx           поиск, фильтры, меню действий, настройки колонок
    PeriodPicker.tsx      выбор месяца/года
    Summary.tsx           Netto / VAT / Brutto + ставки
    DocumentList.tsx      таблица (desktop) / карточки (mobile)
    Pagination.tsx, States.tsx, Popover.tsx
```
